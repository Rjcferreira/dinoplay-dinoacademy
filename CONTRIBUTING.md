# Contribuir

1. Cria um fork e uma branch curta.
2. Mantém todos os recursos dentro do repositório; CDNs e rastreadores são proibidos.
3. Atualiza a versão semântica em `manifest.json`.
4. Executa `node scripts/validate.mjs`.
5. Abre um pull request explicando alterações, testes e impacto para crianças.

Não incluas publicidade, compras visíveis à criança, chat livre, recolha de dados pessoais, conteúdos violentos ou propriedade intelectual sem autorização.
